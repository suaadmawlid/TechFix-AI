# TechFix AI

TechFix AI is an AI-assisted computer troubleshooting system designed to help students and everyday computer users identify common software and computer problems and follow guided troubleshooting steps.

## Why I Built This Project

I became interested in computer troubleshooting from an early stage. 
I often helped family members, neighbors, and classmates with common 
software problems on their phones and computers.

As I studied Software Engineering, this interest became stronger. 
I wanted to understand not only how to fix individual problems, but 
also how software could help users diagnose problems and find suitable 
solutions.

TechFix AI is my attempt to explore this idea by combining my 
troubleshooting experience with Software Engineering and Artificial 
Intelligence.

## Project Goals

The main goals of TechFix AI are:

- Identify common computer and software problems from user descriptions.
- Provide clear, step-by-step troubleshooting guidance.
- Ask follow-up questions when the initial information is not enough.
- Record user feedback about whether a suggested solution worked.
- Explore how machine learning can improve problem classification.
- Build a simple and accessible tool for students and everyday computer users.


## Technology Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Python and Flask

- Database: SQLite

- Development Environment: Visual Studio Code

## How TechFix AI Works

TechFix AI follows a simple troubleshooting workflow:

1. The user describes a computer or software problem.
2. The system analyzes the user's description.
3. A classification component identifies the most likely problem category.
4. The system selects relevant troubleshooting steps from its knowledge base.
5. The user follows the suggested steps one at a time.
6. The system asks whether the problem was solved.
7. User feedback can be used to improve future troubleshooting decisions.

The first version will begin with a rule-based troubleshooting system. 
Machine learning will then be introduced to classify user problem 
descriptions and improve the system's ability to identify the correct 
problem category.

## Initial Problem Categories

The first version of TechFix AI will focus on five common computer and software problem categories:

1. Computer Performance
   - Slow computer
   - Applications taking too long to respond

2. Application Problems
   - An application does not open
   - An application crashes or stops responding

3. Internet and Wi-Fi Problems
   - Wi-Fi is connected but there is no internet
   - Internet connection is unstable

4. Windows Update Problems
   - Windows Update fails
   - Updates remain stuck or do not complete

5. Software Installation Problems
   - Software installation fails
   - Installation shows an error
